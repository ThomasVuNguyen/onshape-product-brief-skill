# Comfy Hardware Standard example

This six-page A4 concept brief was derived from the current Onshape `Total Assembly` in October 2026. The example shows a full-bleed cover and back page, a compact overview and specification, and reference drawings made from CAD views.

The 150 x 200 x 163.1 mm overall envelope came from the visible assembly's GLB bounds. It is a reference measurement, not a tolerance-controlled production dimension. Materials, performance, and production claims were not verified.

Run `python3 build_brief.py` in this directory after installing the repository requirements to regenerate the PDF from the included artwork. The prepared artwork and PDF are viewable examples and are not licensed for reuse. The build script is MIT licensed; the bundled Roboto fonts use the SIL Open Font License in `fonts/OFL.txt`.
